# 解读框架

## 一、三核先行

太阳 = 想成为的样子与核心驱动力；月亮 = 情绪反应与安全感来源；上升 = 对外呈现的第一层壳与行动节奏。

三句话讲清，再展开。三核互相矛盾时，说清矛盾在什么场景下显形，不要强行圆。

## 二、个人行星

水星（表达与思考）、金星（关系与审美）、火星（行动与冲突方式）逐条讲，每条落到一个具体行为。

## 三、社会与外行星

木星（扩张方式）、土星（压力与课题）、天王（突变点）、海王（模糊地带）、冥王（深层执念）。只讲与用户问题相关的部分，不逐个念。

## 四、相位

- 合相 = 两股力量黏在一起，难以分开看。
- 对分 = 拉扯，需要外部情境才显形。
- 四分 = 内耗，越想协调越别扭。
- 三分 / 六分 = 顺滑，容易到不自觉。

先讲最紧的 2~3 个相位，其余略过。

## 五、边界

- 不做医疗诊断、不做投资与法律预测。
- 上升与宫位依赖准确出生时间；时辰不确定时，明确标注这部分结论可能偏。
- 用「倾向」「更容易」，不用「注定」。
- 用户问题超出本命盘能回答的范围（如具体事件时间），直接说明并建议改用行运技能。
