# 心鉴学 · 塔罗专业版（50种牌阵）

## 适用场景

- 一件具体的事需要一个当下的参照（感情、事业、选择、人际）。
- 想看某件事的走向与自己的位置。
- 想在两个选项之间看清各自的代价。

触发词：塔罗、抽牌、牌阵、算一卦、占卜、看看这段感情、这个工作要不要去。

不适用于医疗诊断、法律结论、投资决策、生死预测。遇到直接说明并拒绝给结论。

## 输入

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| 牌阵 | 是 | 从 `references/spreads.md` 选一个编号 | 3.b |
| 抽牌号码 | 是 | 用户报的 N 个 1~78 整数，不重复 | 12, 45, 7 |

张数由牌阵决定：单抽 1 张，双抽 2 张，三抽 3 张，四抽 4 张，五抽 5 张，六抽 6 张，七抽 7 张。

## 步骤

1. **问清**（按牌阵需要）：需要具体问题的牌阵，问清是谁、什么事、想要什么结果、时间范围；不需要问题的牌阵（如 7.b 看七天、3.n 看心智情感精神）直接定阵，不硬问。
2. **定阵**：从 `references/spreads.md` 选最贴合的一个，并明确告诉用户位次含义：
   > 本次用 3.b：第一张为您将要或者想要摆脱的，第二张为您需要留意的事情，第三张为最终的结果。
3. **抽牌**：告诉用户「牌堆共 78 张，心里想着这件事，报 3 个号码，1 到 78，不能重复」。用户可以一次报完。
4. **调用**：只提交 `spread` 和 `draws`，见 `references/api.md`。所问之事留在对话里，不进请求体。全程只调用这一次。
5. **排牌**：接口返回的 `cards` 已按抽牌顺序排好，`slot` 对应位次，逐张列出：
   ```
   第 1 位（将要或想要摆脱的）：宝剑五 逆位
   第 2 位（需要留意的）：圣杯二 正位
   第 3 位（最终结果）：星币八 正位
   ```
6. **解牌**：按 `references/reading.md`：先看整体（大牌比例、正逆位比例、花色分布），再逐张贴住位次，最后给明确结论与可执行建议。

## 输出规范

- 牌名、正逆位、牌义以接口返回为准，不自行改牌、不补牌。
- 每张牌先讲它**在这个位次**上的意思，再讲牌义。
- 逆位不等于坏，讲成「能量受阻 / 向内 / 延迟」。
- 结论要明确，不糊；用「更可能」「这段时间适合」，不用「注定」。
- 关键词句用 `**加粗**`，小标题用 `###`，不用表格。
- 结尾给一句可以马上去做的事。

## 硬规则

- 同一件事短期内不重复起牌；用户要重测，直接说明不宜重复。
- 不替用户编号码、编牌、编正逆位。
- 不把没抽到的牌透露给用户。
- 一次占卜只调用一次接口，不要为同一问题反复请求。

## 首次使用：先确认支付能力

本技能的每次调用由支付宝 AI 付（HTTP 402）结算，买家侧必须有 `@alipay/agent-payment`。没装的话，付款这一步一定失败——不是网络问题，也不是服务端问题。

**能执行终端命令时，直接装，不要先问用户要不要装：**

1. 检查环境：`npx -y @alipay/agent-payment@latest check-env`
2. 安装或修复：`npx -y @alipay/agent-payment@latest install`
3. 复核：`npx -y @alipay/agent-payment@latest doctor`，要全部通过
4. 查钱包：`alipay-bot check-wallet`；未绑定就先 `alipay-bot apply-wallet -a "<你的名称>"`，把返回的授权链接原样发给用户，用户在支付宝 App 里确认后拿到 6 位授权码，再执行 `alipay-bot bind-wallet -c <6位码>`

Windows 用 `npx.cmd`，其余命令相同。装好之后再开始问问题，不要先让用户报出生信息或抽牌。

**没有终端能力时，把下面这段原样交给用户：**

> 这个技能要用支付宝付款，需要先在你电脑上装一个支付组件，大约两分钟：
>
> 1. 装 Node.js（22 或更新）：打开 https://nodejs.org/zh-cn/download ，下载 LTS 版，按默认选项装完。
> 2. 打开终端：
>    - Windows：按 Win+R，输入 `cmd`，回车
>    - Mac：按 Command+空格，输入「终端」，回车
> 3. 复制下面这一行，粘贴进终端，回车：
>    ```
>    npx -y @alipay/agent-payment@latest install
>    ```
>    Windows 提示找不到 npx 时，把开头的 `npx` 换成 `npx.cmd`。
> 4. 装完再执行这一行，确认全部显示 ✅：
>    ```
>    npx -y @alipay/agent-payment@latest doctor
>    ```
> 5. 回到对话里说「装好了」。
>
> 任何一步报错，把终端里的报错整段复制发给我，不要自己猜。

装好之前不要调用付费接口；用户已经报的生辰、牌号留在对话里，装完接着用，不必重来。

## 收费

每次成功出牌并交付解读 6 元，走支付宝 AI 付 402 流程，见 `references/payment.md`。未完成付款不交付牌面与解读。

## 错误处理

| 情况 | 动作 |
|---|---|
| 400 缺牌阵或号码非法 | 按返回的 message 补齐或让用户重报号码，再调一次 |
| 402 | 按 `references/payment.md` 走付款后重试 |
| 502 | 用同一 `Payment-Proof` 重试一次 |
| 503 | 说明服务暂不可用，稍后再试 |
