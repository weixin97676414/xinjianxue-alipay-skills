# 心鉴学 · 占星运势专业版

## 适用场景

- 本命盘已知，想知道**现在这一段**的走向。
- 问今年、这半年、这个月的重点议题。
- 某件事正在发生，想看它落在哪个宫位、影响多久。

触发词：行运、运程、今年运势、最近运势、流年星、过境、当下该注意什么。

只要本命结构、不涉时间段的，用「西方占星」技能；本条专讲行运。

## 输入

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| 出生年 | 是 | 阳历四位年份 | 1995 |
| 月 / 日 | 是 | 数字 | 8 / 4 |
| 时 / 分 | 是 | 24 小时制 | 5 / 52 |
| 出生地 | 是 | 省+市 | 浙江杭州 |
| 国家 | 否 | 默认 CN | CN |
| 当前所在地 | 是 | 行运盘按所在地当地时间起算 | 上海 |

当前所在地**必须问**。行运时刻取决于所在地当地时间，缺了会算错起算时刻，不能默认成出生地。

## 步骤

1. 采集上表信息，确认当前所在地。
2. 调用服务（契约见 `references/api.md`），取回行运盘。
3. 按 `references/reading.md` 解读。
4. 呈现顺序：这段时间的主题 → 关键过境 → 压力与机会 → 落到用户的问题。

## 输出规范

- 宫位、星座、星体必须以接口返回为准。
- `meta.transit_time` 是本次行运的起算时刻，`transit_time_basis` 说明它按什么时区取；用户问「算的是哪个时间」时照实回答。
- 讲时间段，不讲具体某天必然发生什么。
- 用「这段时间更容易」「窗口期在」，不用「一定会」。
- 关键词句用 `**加粗**`，小标题用 `###`，不用表格。

## 首次使用：先确认支付能力

本技能的每次调用由支付宝 AI 付（HTTP 402）结算，买家侧必须有 `@alipay/agent-payment`。没装的话，付款这一步一定失败——不是网络问题，也不是服务端问题。

**能执行终端命令时，直接装，不要先问用户要不要装：**

1. 检查环境：`npx -y @alipay/agent-payment@latest check-env`
2. 安装或修复：`npx -y @alipay/agent-payment@latest install`
3. 复核：`npx -y @alipay/agent-payment@latest doctor`，要全部通过
4. 查钱包：`alipay-bot check-wallet`；未绑定就先 `alipay-bot apply-wallet -a "<你的名称>"`，把返回的授权链接原样发给用户，用户在支付宝 App 里确认后拿到 6 位授权码，再执行 `alipay-bot bind-wallet -c <6位码>`

Windows 用 `npx.cmd`，其余命令相同。装好之后再开始问问题，不要先让用户报出生信息或抽牌。

**没有终端能力时，把下面这段原样交给用户：**

> 这个技能要用支付宝付款，需要先在你电脑上装一个支付组件，大约两分钟：
>
> 1. 装 Node.js（22 或更新）：打开 https://nodejs.org/zh-cn/download ，下载 LTS 版，按默认选项装完。
> 2. 打开终端：
>    - Windows：按 Win+R，输入 `cmd`，回车
>    - Mac：按 Command+空格，输入「终端」，回车
> 3. 复制下面这一行，粘贴进终端，回车：
>    ```
>    npx -y @alipay/agent-payment@latest install
>    ```
>    Windows 提示找不到 npx 时，把开头的 `npx` 换成 `npx.cmd`。
> 4. 装完再执行这一行，确认全部显示 ✅：
>    ```
>    npx -y @alipay/agent-payment@latest doctor
>    ```
> 5. 回到对话里说「装好了」。
>
> 任何一步报错，把终端里的报错整段复制发给我，不要自己猜。

装好之前不要调用付费接口；用户已经报的生辰、牌号留在对话里，装完接着用，不必重来。

## 收费

每次成功出一份行运盘 6 元，走支付宝 AI 付 402 流程，见 `references/payment.md`。未完成付款不交付解读。

## 错误处理

| 情况 | 动作 |
|---|---|
| 400 参数不合法 | 按 error 修正后重试一次 |
| 400 当前所在地无法识别 | 让用户补全「国家+省/州+城市」后重试 |
| 402 | 按 `references/payment.md` 走付款后重试 |
| 500 | 重试一次；仍失败则说明服务暂不可用，不编造行运 |
